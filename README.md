# 🔍 Fake News Detector

A machine learning project that detects fake news using NLP and TF-IDF.

## Tech Stack
Python, Scikit-learn, NLTK, Streamlit

## How to Run
1. pip install -r requirements.txt
2. Add True.csv and Fake.csv inside dataset/
3. python week1_clean.py
4. python week2_model.py
5. streamlit run app.py

## Dataset
ISOT Fake News Dataset (Kaggle)
